# Remaining work and blockers

Snapshot date: 2026-11-07. This records why the roadmap is not complete on this machine and what can
still be implemented later.

## Implementable in a future session

| Item | Why it remains | Next step |
| --- | --- | --- |
| Passkeys/WebAuthn | Requires a browser authenticator test and a small registration UI. | Add `@simplewebauthn/server` endpoints, credential table and Playwright virtual-authenticator test. |
| Browser login UI | Service is API-only. | Serve login, verification, reset, sessions and API-token pages with CSRF and CSP tests. |
| Nested-board project share | Project snapshots are per board and the service has no project parent tree. | Add project parent ids and a documented nested inclusion policy, then recursive share payload tests. |
| Public sharing warning UI | API warning exists but no share UI. | Build the share dialog with an explicit acknowledgement before enabling links. |
| Asset watermark | Needs an image pipeline and platform decision. | Add a supported image pipeline and per-share watermark rendering with tests. |
| Encryption at rest | Depends on the database and volume platform. | Document SQLCipher or encrypted-volume deployments and add a startup check. |
| Application-level encryption | Needs key management and migration design. | Design envelope encryption for sensitive fields and rotation. |
| Server-side rich-text sanitising | The service returns JSON and does not render card HTML. | If a server-rendered share page is added, sanitise there and test XSS payloads. |
| Larger load and abuse run | Only a low-volume smoke harness is run here. | Run k6 or equivalent against a staging host with production-like limits. |
| P0/P1 defect review | Requires issue history and human triage. | Freeze the release candidate and review the tracker. |
| Live incident drill | Runbook exists, not exercised. | Rotate secrets and restore a backup in staging. |

## External blockers

| Blocker | Requirement |
| --- | --- |
| Windows code signing | A trusted code-signing certificate and timestamp service. |
| macOS signing and notarisation | Apple Developer account, Developer ID certificate, notary credentials and a macOS runner. |
| Universal macOS build | Build both arm64 and x64 slices and combine them on macOS. |
| Linux packages | Execute the Ubuntu matrix job, then verify AppImage and `.deb` on X11 and Wayland. |
| Flatpak | Write and test a pinned-runtime manifest; this is not generated by Tauri. |
| Android | Tauri mobile port, Android SDK, signing key and tablet testing. |
| iOS | Mac runner, Apple Developer account, provisioning profiles and App Store review. |
| External penetration test | Independent security test before advertising production self-hosted use. |
| Legal and support review | Privacy notice, terms, support contact and disclosure address. |

## Out of scope for Milestones 1 to 7

The AI assistant (Milestone 8) is intentionally not started. It needs a separate consent, tool
gateway, browser isolation, audit and prompt-injection test design before any implementation.
